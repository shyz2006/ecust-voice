## 当前功能

- 华理心声：近24小时新增讨论 Top 3，每题最新三个原帖链接，统一十二类议题。
- 校内趋势：近十日走势、整数篇数的次日参考。
- 青年热点：每平台十条，按本站升温指标排序，每卡展示关注焦点。
- 梗文化：从近期采集内容动态发现表达，统一十张简介与用例卡片；达到用例门槛后检索并核对释义。
- 育人工坊：Query / Media / Insight → ReportEngine，报告四章、正文自然分页；另含校园周报。
- 数据账本：采集与分类统计、含今天的十四个北京时间日历日用量卡片。

配置分为模型服务、博查检索、Resend邮件，分别保存。周报发送日、时刻与提前截稿时间可自定义；交接核查时实际为**每周三21:30截稿、22:00发送**，并非早期默认的周五14:00。

当前博查返回额度相关HTTP403，最新上线验收有21个候选表达、0个完成释义核对的条目，显示十张用法观察卡片。B站和抖音提供具体内容地址、搜索及复制入口，外部平台访问仍受其登录与验证规则影响。

## 源码与运行

`production/` 对应容器 `/app` 下的应用源码；`host-deployment/` 保存主机部署配置参考；`validation/` 保存发布脚本和验收记录。两个入口模板 `production/templates/index.html` 与 `production/CampusPulse/templates/pulse.html` 必须保持一致。

生产配置、数据库和报告通过独立挂载持久化，源码推送不包含业务数据与凭据。现有部署脚本带机器绝对路径，基础镜像和依赖尚需进一步固定；迁机与发布请按交接文档操作。
