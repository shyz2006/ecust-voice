# 校园与青年事件分析报告

## 1. 事件概述与事实核验
围绕用户主题核对事件主体、时间、地点、已确认事实与争议。使用三引擎提供的原始来源和日期，逐项引用实际来源链接；区分公开报道、当事人说法与分析推断。资料缺口直接说明。目标500—650字。

## 2. 传播脉络与公众关注
根据可核实报道和采集记录梳理关键节点、平台差异、主要诉求与不同观点。只使用材料中的传播量和互动量；没有数据时采用定性说明。目标500—650字。

## 3. 心理与社会机制
在具体证据基础上，从社会认同、归因、群体互动、情绪表达等适用概念解释现象；明确替代解释和推断范围。避免个体诊断和空泛理论堆砌。目标500—650字。

## 4. 影响研判与后续观察
分析对学生、校园沟通及社会讨论的已发生影响与可能影响，列明触发条件、观察指标、信息缺口和结论边界。结尾附主要来源及日期。目标500—650字。

全文要求：2400字左右，以上四章，导出四页A4。沿用微舆的Query/Media/Insight取证和Report汇总流程。只输出事件研究报告；活动策划、班会教案、团辅设计、人员物资预算、思政活动和执行排期均不属于本报告内容。使用朴素专业的中文，保留事实出处；禁止编造统计数字、来源、学生案例或学校行动。图表仅在有可靠数字且确有必要时使用，核心结论必须以正文写出。
