# 华理校园笔记 · 本机定时同步助手

1. 解压下载的 ZIP，保持整个目录完整。
2. 在已登录小红书的 Edge 打开 `edge://extensions`，开启开发人员模式，选择“加载解压缩的扩展”，选择包含 manifest.json 的目录。请先检查源码及权限再加载。
3. 在校园平台“配置 → 检索与采集 → 小红书本机定时同步”生成同步码。
4. 点击 Edge 工具栏中的本助手，将同步码粘贴一次，选择每6／12／24小时，点击“连接并开启自动同步”。首次连接会立即尝试同步。
5. 助手显示上次结果和下次时间。电脑、浏览器开启且小红书登录有效时自动运行；浏览器重新开启时补做已到期的一轮。

每轮正常打开一个搜索页，轮换“华理”“华东理工大学”“华理 奉贤”“华理 徐汇”，读取已加载的公开笔记卡片，每轮最多30条。不会自动滚动或调用隐藏接口。遇到登录、安全验证或无有效卡片时暂停，保留搜索页供本人检查，处理后点击“恢复自动同步”。正常完成则关闭本轮创建的搜索页。

同步码仅允许上传校园笔记，90天有效。服务器保存摘要哈希，可随时在校园平台撤销或重建；旧码随即失效。助手使用浏览器本地存储保存专用同步码，不导出小红书 Cookie、密码或登录会话。

扩展权限：scripting 用于读取公开卡片；activeTab 用于手动导出当前页；alarms 用于定时；storage 用于保存设置和运行状态。站点权限仅限小红书和指定校园平台上传接口，没有 cookies、debugger、代理或全部网站权限。

手动备用：在小红书搜索华理，打开助手“手动导出备用”读取当前页、下载JSON，在校园平台相同设置中的“手动导入备用”确认预览并导入。

真实页面结构可能变化，首轮需核对同步结果。它依赖本机运行，不是服务器全天独立采集。原帖发布时间与互动量未知时保持未知，按首次采集归档，页面标明本机来源。

## 1.2.0 更新

更新时将新版文件覆盖到原来加载的扩展目录，再到 Edge 扩展管理页点击该扩展的刷新按钮。沿用同一目录可保留同步码，通常无需重新生成。

修复可见卡片使用隐藏笔记链接、标题位于封面外等布局的读取；恢复或立即同步时优先读取当前已打开的华理搜索页。新增“同步当前搜索页到平台”，可以直接上传，无需先导出文件。后台页面等待延长至约45秒；失败时显示链接、卡片、标题和华理匹配数量，便于定位。验证码或访问限制仍会暂停。

用户看到华理卡片但旧版提示无结果，已通过兼容性测试复现两种旧版漏读。真实小红书页面仍需要更新后确认，不将模拟测试视为真实采集成功。
